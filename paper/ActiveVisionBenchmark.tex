\section*{Introduction}
ActiveVisionBenchmark is a compact Python library whose primary purpose is to
construct visual stimuli, with a specific emphasis on oriented visual-flow
patterns.

The reference stimulus design is documented in:
\href{https://laurentperrinet.github.io/sciblog/posts/2025-04-24-orienting-yourself-in-the-visual-flow.html}{Orienting yourself in the visual flow}.

Rather than positioning the project mainly as a benchmark suite, the library is
now centered on reproducible stimulus creation for experimental pipelines in
behavioral, neurophysiological, and computational vision studies.

\section*{Stimulus definition}
The implemented stimulus is based on three principles:
\begin{compactenum}
    \item A visual-flow field defines local motion direction around a configurable focus of expansion.
    \item Local oriented elements are generated from that flow direction, with a configurable angular offset.
    \item The final stimulus is composited on a controlled-noise background with explicit random seeds for reproducibility.
\end{compactenum}

This formulation makes it straightforward to manipulate interpretable variables
(density, orientation offset, flow origin, contrast) while preserving a compact
single-file implementation.

\section*{Library scope}
The library includes:
\begin{compactitem}
    \item low-level generators (noise and Gabor primitives),
    \item a dedicated visual-flow stimulus constructor,
    \item optional benchmarking utilities retained for downstream model-comparison workflows.
\end{compactitem}

\section*{Conclusion}
ActiveVisionBenchmark should be used first as a stimulus-construction library.
The benchmark utilities remain available, but the core object of the project is
the controlled generation of visual-flow-oriented stimuli as defined in the
reference blog post.

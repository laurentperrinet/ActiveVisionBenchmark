\begin{abstract}
We introduce \avb{}, a single-file Python library for benchmarking active vision
algorithms.  Active vision refers to perception systems that can actively control
where they direct their gaze or attention to optimally gather information from a
visual scene.  \avb{} provides (i) configurable stimulus generators including Gabor
patches and visual-search arrays, (ii) a minimal model interface that decouples
the benchmark harness from algorithm design, (iii) a foveation operator that
simulates eccentricity-dependent resolution loss, and (iv) standard signal-detection
metrics—accuracy, hit rate, false-alarm rate, and \dprime{}—as well as the
scanpath-level metric of search efficiency.  Two reference models are included: a
uniform random baseline and a contrast-saliency model with inhibition of return.
The library has a single mandatory dependency (\texttt{numpy}) and optional
dependencies on \texttt{scipy} and \texttt{matplotlib}.  The entire implementation
fits in one \texttt{.py} file to maximise portability and ease of embedding in
existing workflows.
\end{abstract}

\textbf{Keywords:} active vision, visual search, saccades, benchmark, Python,
foveation, signal-detection theory.

\section{Introduction}
\label{sec:intro}
% ---------------------------------------------------------------

Active vision—the paradigm in which a perceiving agent controls its own sensory
input by moving its eyes, head, or attention—has been a central concept in
computational and biological vision research
\citep{Bajcsy1988,Yarbus1967,Tatler2011}.  Unlike passive, single-shot recognition,
active vision systems must balance \emph{exploration} (learning the scene layout)
with \emph{exploitation} (acting on accumulated evidence), all under strict limits
on the number of fixations that can be made before a decision is required.

Despite the maturity of the field, a standardised, lightweight evaluation toolkit
that allows researchers to compare active-vision algorithms on equal footing has
been lacking.  Existing benchmarks are either tightly coupled to specific datasets
\citep{Judd2009,Kummerer2016} or require heavy software stacks that make
reproducibility across labs difficult.

\avb{} fills this gap by providing a minimal yet complete harness that can be
dropped into any Python environment with a single file copy.  Its design
emphasises:

\begin{itemize}
  \item \textbf{Portability.} A single \texttt{.py} file with one mandatory
        dependency (\texttt{numpy}).
  \item \textbf{Extensibility.} A clean abstract-base-class interface
        (\texttt{ActiveVisionModel}) that makes it trivial to plug in custom
        algorithms.
  \item \textbf{Reproducibility.} All stochastic components accept a
        \texttt{seed} argument and use \texttt{numpy.random.Generator}.
  \item \textbf{Evaluability.} Standard signal-detection theory (SDT) metrics
        are computed automatically from trial results.
\end{itemize}

The remainder of this paper is organised as follows.
Section~\ref{sec:background} reviews relevant background.
Section~\ref{sec:design} describes the library design and API.
Section~\ref{sec:experiments} presents experiments comparing the two bundled models.
Section~\ref{sec:conclusion} concludes with directions for future work.

% ---------------------------------------------------------------
\section{Background}
\label{sec:background}
% ---------------------------------------------------------------

\subsection{Active Vision and Saccadic Search}

Human vision is acutely non-uniform: the fovea, covering approximately $2°$ of
visual angle, provides high-resolution colour information while the periphery
offers rapidly decreasing acuity with eccentricity \citep{Wandell1995}.  To
compensate, humans make $3$–$5$ saccadic eye movements per second, redirecting
the fovea to informative regions \citep{Henderson2003}.  A computational active
vision system mimics this by selecting a sequence of fixation locations that
maximises information gain within a budget of $N$ fixations.

\subsection{Visual Search}

The classical visual-search paradigm \citep{Treisman1980} asks observers to detect
a target item among distractors.  The \emph{set size} (number of items) and target
salience jointly determine search efficiency, measured as the slope of the
reaction-time vs.\ set-size function.  \avb{} operationalises this as the ratio of
expected fixations under random search to observed fixations under the model.

\subsection{Signal Detection Theory}

Signal detection theory \citep{Green1966} separates \emph{sensitivity} (\dprime{})
from \emph{criterion} by decomposing decisions into hits (correct target-present
responses) and false alarms (incorrect target-present responses on absent trials).
\avb{} reports both rates and computes \dprime{} using the loglinear correction
\citep{Hautus1995} to handle boundary cases.

\section{Library Design}
\label{sec:design}
% ---------------------------------------------------------------

\subsection{Architecture Overview}

\avb{} is organised around four conceptual layers, all housed in the single file
\texttt{ActiveVisionBenchmark.py}:

\begin{enumerate}
  \item \textbf{Stimulus layer.} Functions that generate synthetic visual stimuli.
  \item \textbf{Task layer.} The \texttt{VisualSearchTask} class, which composes
        stimuli into \texttt{Trial} objects.
  \item \textbf{Model layer.} The abstract \texttt{ActiveVisionModel} interface
        and two concrete implementations.
  \item \textbf{Benchmark layer.} The \texttt{Benchmark} engine and the
        \texttt{BenchmarkResult} container.
\end{enumerate}

\subsection{Stimulus Generation}

Two primitive generators are provided:

\paragraph{\texttt{make\_gaussian\_noise}.}
Returns a 2-D array of Gaussian luminance noise with configurable mean and
standard deviation, useful as a neutral background.

\paragraph{\texttt{make\_gabor\_patch}.}
Generates a Gabor patch (sinusoidal grating modulated by a Gaussian envelope)
parametrised by spatial frequency~$f$, orientation~$\theta$, phase~$\phi$, and
envelope width~$\sigma$:

\begin{equation}
  G(x,y) = \exp\!\left(-\frac{x^2+y^2}{2\sigma^2}\right)
            \cos\!\left(2\pi f\, x_r + \phi\right),
  \quad x_r = x\cos\theta + y\sin\theta.
  \label{eq:gabor}
\end{equation}

\paragraph{\texttt{make\_search\_array}.}
Composes a search array by pasting distractors and an optional target onto a
Gaussian-noise canvas.  It returns both the image and the target location (or
\texttt{None} for target-absent trials), making it suitable for supervised
evaluation.

\subsection{Task and Trial}

\texttt{VisualSearchTask} wraps the stimulus layer to provide a reproducible
stream of \texttt{Trial} objects.  Each trial has a \texttt{target\_present}
flag and, when applicable, the ground-truth \texttt{target\_location}.  The
\texttt{generate\_dataset} method produces a list of $N$ trials, enabling
batch evaluation.

\subsection{Model Interface}

The abstract base class \texttt{ActiveVisionModel} defines three methods:

\begin{description}
  \item[\texttt{reset(image)}] Initialise model state for a new trial.
  \item[\texttt{next\_fixation(foveated\_image, fixation\_history)}]
        Given the current foveated view and the list of past fixations, return
        the next fixation location $(r, c)$.
  \item[\texttt{make\_decision()}] Return a Boolean target-present decision at
        the end of the fixation budget.
\end{description}

This interface cleanly separates the \emph{what to look at} (the scanning
policy) from the \emph{is the target present} (the detection decision),
allowing users to mix and match components.

\subsubsection{RandomSearchModel}

The random baseline selects fixation locations uniformly at random over the image
and decides target presence by a fair coin flip.  Its expected accuracy is $50\%$,
providing a lower bound for detection performance.

\subsubsection{SaliencySearchModel}

The saliency model computes local RMS contrast using a sliding window:

\begin{equation}
  S(x,y) = \sqrt{\mathbb{E}_{W}[I^2] - \mathbb{E}_{W}[I]^2},
  \label{eq:saliency}
\end{equation}

where $\mathbb{E}_W[\cdot]$ denotes averaging over a square window $W$ centred
at $(x,y)$.  Fixations are drawn greedily from the maximum of $S$ with
\emph{inhibition of return} (IoR): a circular region of radius $r_{\text{IoR}}$
around each visited location is zeroed before the next fixation is selected.

\subsection{Foveation Operator}

The \texttt{foveate} function simulates foveal processing by blending the
original image (inside a circular foveal region of radius $r_f$) with a
Gaussian-blurred version (outside):

\begin{equation}
  F(x,y) = M(x,y)\,I(x,y) + \bigl(1 - M(x,y)\bigr)\,I * G_{\sigma_p}(x,y),
  \label{eq:foveation}
\end{equation}

where $M(x,y) = \mathbf{1}[\|(x,y) - (r,c)\| \le r_f]$ is the foveal mask
and $G_{\sigma_p}$ is a Gaussian kernel with periphery blur sigma~$\sigma_p$.

\subsection{Benchmark Engine}

\texttt{Benchmark.run(model, trials)} iterates over trials, calling
\texttt{model.reset}, then \texttt{model.next\_fixation} up to
\texttt{max\_fixations} times, followed by \texttt{model.make\_decision}.
Wall-clock time is recorded per trial.  The \texttt{compare} method evaluates
multiple models on identical trials, ensuring a fair comparison.

\subsection{Metrics}

\texttt{BenchmarkResult} exposes the following scalar metrics:

\section{Experiments}
\label{sec:experiments}
% ---------------------------------------------------------------

\subsection{Setup}

We generated $200$ trials using \texttt{VisualSearchTask} with image size
$256 \times 256$ pixels, $10$ distractors per trial, and a target-present
probability of $0.5$.  Both models were allocated a budget of $20$ fixations.
All experiments used fixed seeds for reproducibility.

Listing~\ref{lst:example} shows the complete code required to reproduce
the comparison.

\begin{lstlisting}[caption={Reproducing the benchmark comparison.},
                   label={lst:example}]
import numpy as np
from ActiveVisionBenchmark import (
    Benchmark, RandomSearchModel, SaliencySearchModel, VisualSearchTask
)

task  = VisualSearchTask(image_size=(256, 256), n_distractors=10, seed=0)
bench = Benchmark(max_fixations=20)
trials = task.generate_dataset(n_trials=200)

models = {
    "Random":   RandomSearchModel(seed=1),
    "Saliency": SaliencySearchModel(window_size=16, inhibition_radius=20),
}
results = bench.compare(models, trials)

for name, res in results.items():
    print(res.summary())
\end{lstlisting}

\subsection{Results}

Table~\ref{tab:results} summarises the performance of both models.
The saliency model achieves higher accuracy and a larger \dprime{} than
the random baseline, confirming that contrast-based guidance is informative
for the conjunction search arrays used here.  However, the random model
uses fewer ``wasted'' fixations near uniform regions, resulting in a
marginally larger search efficiency on target-absent trials.

\section{Discussion}
\label{sec:discussion}
% ---------------------------------------------------------------

\avb{} deliberately keeps its scope narrow: it is a harness for detection-based
active-vision experiments, not a full simulation environment or a dataset library.
Several extensions are left for future work:

\begin{itemize}
  \item \textbf{Real-image support.} A \texttt{NaturalImageTask} class loading
        images from common datasets (e.g., COCO \citep{Lin2014}) would broaden
        applicability.
  \item \textbf{Bayesian models.} Integrating an ideal-observer model
        \citep{Najemnik2005} that computes the theoretically optimal fixation
        sequence would provide an upper-bound reference.
  \item \textbf{Eye-tracking integration.} Adapters for loading human fixation
        data (e.g., from EyeLink recordings) would enable direct
        human-vs.-algorithm comparisons.
  \item \textbf{Temporal dynamics.} Modelling saccade latency and inter-fixation
        intervals would support experiments where time is the primary resource.
\end{itemize}

% ---------------------------------------------------------------
\section{Conclusion}
\label{sec:conclusion}
% ---------------------------------------------------------------

We have described \avb{}, a self-contained, single-file Python toolkit for
benchmarking active vision systems.  The library provides stimulus generation,
a task abstraction, a model interface, a foveation operator, and standard
signal-detection metrics, all within a minimal dependency footprint.  We hope
that \avb{} will lower the barrier to reproducible comparisons of active-vision
algorithms across the neuroscience and computer-vision communities.

The library is available at
\url{https://github.com/laurentperrinet/ActiveVisionBenchmark}.

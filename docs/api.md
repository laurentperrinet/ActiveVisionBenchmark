# API reference

The whole library is a single module, {mod}`ActiveVisionBenchmark`. Its documentation is
generated from the docstrings with `sphinx.ext.autodoc` and `sphinx.ext.napoleon`. The
module docstring below gives the equations of the model and the table of its variables;
the classes follow in the order of the file: stimuli, tasks, models and benchmarks.
